# OpenJarvis Mobile — portable core

Experimental iOS-focused port of OpenJarvis. This directory currently contains the portable Swift runtime and tests from v0.2.0; it is not a standalone iOS application yet.

From mobile/ios run `swift test` using Swift 6.x. The portable package has no external Swift dependencies. Native iOS app, Rust C ABI bridge and build scripts are planned in the next import PR.
