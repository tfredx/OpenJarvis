# Mobile pull request checklist

- [ ] Targets ios/main, not upstream or main
- [ ] Focused scope and linked issue when available
- [ ] Tests and exact results; unrun tests explicitly noted
- [ ] Source provenance and lockfiles updated as needed
- [ ] Permission, privacy and security implications reviewed
- [ ] No credentials or personal data in diff or logs
- [ ] Documentation, roadmap and handoff updated
- [ ] Required checks green and owner review complete

Use draft PRs for incomplete implementation. Do not merge a failed gate or tag an unvalidated release.
