# ADR 0005 — Single-owner session coordinator (proposal)

Baseline 422337e89ec876e777051e46470cad85303c1e7a, PR #15 CI 45936370068 passed 31 Swift, 10 Rust, 8 hosted tests and both app builds; unsigned artifact 15171057055. Post-merge run 45937626321 was still executing at observation. Issue #14.

SessionCoordinator on MainActor exclusively owns the active Agent, marks busy across awaits, validates generation and active ID before publishing results, and compares persisted Snapshot to expected in-memory state before and after operations. It invalidates on mismatched or unreadable data. Releases old writer before repository transitions; restores only an unchanged and ready selection after a failed transition. No Agent references escape. No new permissions or model-facing session CRUD. AppState has synchronous startup, one task, cancellation without early writer release, readiness gate, cleared draft/speech on switch, visible error banner, and Shortcuts prefill only when ready and resolved. Session list supports create, select, rename, confirmed delete; erase-all covers all sessions after pending tasks resolve. Version 0.3.2 development build. Existing root file protection and backup exclusion preserved, hardware behavior pending. Session isolation is local, not a separate OS security sandbox; no multi-process coordination.

Seven portable coordinator tests and two hosted native tests added. Expected total 58 (38 Swift, 10 Rust, 10 hosted); not yet executed for this proposal. CI must confirm Swift concurrency/type checking, native UI compilation, test results and artifact publishing. No UI automation or physical-device test claimed. No SQLite or full upstream SessionStore integration. Issue #14 remains open for actual device migration and session UI validation.
